# README showcase media

These are actual application screenshots captured locally with a separate,
non-production demonstration database. Conversation text and agent definitions
are seeded examples for privacy, not fresh LLM output or a claim of new execution.
The neutral landscape film comes from the recorded two-GPU Wan acceptance job;
the two fully clothed image examples are copies of previously recorded local
LUSTIFY Generate/Recompose results from the developer preview folder.

The capture does not read/export the operator's production Library. No NSFW
material, personal conversations, account pages or credentials are selected.
The screenshot helper only forwards whitelisted native telemetry/capability GETs;
it launches no new model, GPU generation or agent workflow.

`station-tour.mp4` is a 12-second Hyperframes 0.8.205 composition of the selected
screenshots, rendered locally with software browser rendering. The GIF is a
reduced-resolution derivative for GitHub README display. This is a product tour, separate
from AI Station's model-generated-video benchmarks. Telemetry and update checks
were disabled for the renderer. Neither format implies automated new inference.

The owner reviewed and approved these four screenshots and GIF/MP4 tour for
publication on 2026-10-26. Only the approved subset is included.
The exact local sources, capture checks and asset hashes are recorded under
ignored `data/acceptance/readme-showcase-20261026/`.
