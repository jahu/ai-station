# Final answers after completed tools

Actual Creative Studio qualification, 2026-11-12: the ordinary assistant produced
a complete 95.633-second full-HD film with its real narration, music and generated
media. All stages completed. The final chat response nevertheless promised to
inspect a workspace and produce a 75-second film, then printed literal `glob`
tool-call markup. No such tool was dispatched. A successful pipeline did not
prove a correct user-facing answer.

The frozen chat context had placed observed results before an actionable
“Current user request”, without making the completed tool phase explicit. The
model treated the original instruction as new work. The response must instead
answer from already collected facts and delivered results.

The proposed context builder names the final-answer phase, quotes the exact
original request as reference data, retains the existing bounded observations,
and places the server-selected reply task last. Its system rule permits no tool
calls, restart plans or promises of new execution. Actual values must remain
distinct from requested estimates. Ordinary chat without observations retains
its existing context. Original messages, receipts and the failed answer remain
inspectable; no history is rewritten. This introduces no tool, permission,
provider change, schema migration or network authority.

Regression coverage must preserve conversation history, custom system guidance,
quoted adversarial data, references, bounds and ordinary streaming chat. Repeat
the actual final response with the recorded completed observations, using an
ordinary owned chat Run; do not regenerate the film or fake a tool receipt.
Actual model qualification remains pending until that response is inspected.

Actual qualification with the same selected local model and the real completed
film receipts now starts from the delivered film, reports its measured 95.6-second
runtime against the requested 75 seconds, emits no fake tool calls and omits
internal IDs. It also distinguishes a produced file from visual inspection.
Only a normal reply Run was executed; no media task or receipt was fabricated.
The observations fit the existing context bound and are kept as structured data;
large excerpts retain the prior bound without truncating the final reply task.
This qualifies the identified final-answer framing defect, not a guarantee that
all generated prose is correct or that the film is publication-ready.
