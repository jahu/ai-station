# Rendered public sources before local agent work

An operator-reviewed public page may require JavaScript before its actual text or
numbers exist. Existing Browser report agents can capture it, but local-code and
Python/data definitions currently reject Browser alongside their execution tool.
This increment composes the already operational browser with those same local
workflows; it does not create another browser or give generated code networking.

Use the existing explicit Browser tool and reviewed 1–3 public URLs in Agents
and conversation agent-definition cards. Retain the exact selected tool set in
either selection order; never silently substitute static GET or enable Browser
because web search is available. Assisted drafts may propose Browser only with
current-user URLs. External coding remains an exclusive execution family.

A source is an ordinary native `browser` Run with only browser/network_read,
shared frozen definition and original deadline. Keep the current source order
(search, search pages, static fetch, rendered pages), then an ordinary local
context handoff. Browser Stop/recovery/SSRF/private-container behavior remains
unchanged. No credentials, login/browser automation, arbitrary URL discovery or
screenshot Vision is added. Every reviewed rendered page must have successful
readable text before creating code or offline analysis.

Validate the actual saved raw browser JSON hash, source Run, reviewed URL list,
page count and the deterministic compact observation projection. Existing raw
network audit differs deliberately from the compact inference observation; use
one shared projection, not weaker equality or duplicated unchecked metadata.
Bind every source to the exact workflow manifest/dependencies/deadline/definition
and require the Browser permission on its native step and handoff. Keep rendered
text, screenshot references, timestamps and truncation provenance inspectable.
Screenshots are references, not model pixel observations. No page instructions
can widen tools, permission, file scope or runtime budget.

Local-code excerpts feed the existing isolated worktree chain. Python gets the
existing bounded immutable source JSON through its read-only input map; it can
combine reviewed files and rendered sources and has no network. Repairs reuse
that capture; no implicit repeat render. Captured follow-ups remain offline with
source verification. Model and result/PNG/Excel/text contracts are unchanged.

Qualification must cover both execution families and selection orders, actual
worker/dependency handoff, malformed/changed/failed sources, permission denial,
Stop/expiry and assisted draft scope. Run required complete local gates and
compiled desktop/phone inspection, exact Docker/Compose and reviewed develop
rollout. Reuse unchanged native Browser acceptance only after source comparison;
synthetic browser/inference tests do not establish real-page or GPU acceptance.
A focused real public JavaScript capture with local analysis can follow rollout
without credentials or downloaded models, preserving the operator model preset.
The full product remains open after this increment.
