# Natural image continuations

After a website/design prompt, **Wygeneruj tę grafikę** must use image generation,
not become another ordinary answer because Web is enabled. Recognize common
graphic/illustration/poster/banner wording in the existing deterministic image
route, including its Generate → Video form. Requests to write a prompt/brief
stay text/website questions; image words inside that request cannot launch image
generation. Agent/project intent keeps priority.

Reuse the current page-reader/image-brief/photo chain. A referential graphic
request may reuse the latest verified same-conversation page/visual evidence;
never search again or repeat Browser/Vision to replace that saved source. A
changed source or Stop must prevent image publication. New unrelated scenes keep
their existing routing; this is not arbitrary multi-step planning.

After a generated image, natural Inspect/Upscale/Edit/Animate references must also work
when ordinary Web is available. An exact query or explicit JavaScript request
retains its authority and prevents implicit source selection. A resolved media
command consumes its verified image, not a search; disable Web only on that
effective backend action, preserving the user's composer preference and original
idempotent request receipt. The same availability rule applies to explicitly
selected non-research image/audio/video actions. Exact research options still
require their existing compatible scopes; no project/agent/runtime policy is
relaxed. Keep same-conversation selection, unique final image,
trash/status checks, explicit-input/worktree precedence and Chat/Work policy.
A failed latest image task without an output cannot revive an older image.
Generic description after a text answer stays conversational; pixel inspection
must be bound to the current result or an explicit visual reference.

Deterministic image edits, recomposition, Upscale, speech and direct generation
without a research brief must not require a ready/configured Chat provider.
Actual text inference (including a researched image brief or audio answer) still
uses the selected provider and its permission/secret checks.

Use the existing Tasks, typed image/media requests, owned native execution,
resource admission, cancellation and conservative recovery. Add no executor,
host endpoint, model download, schema change or external AI. Normal tests use
fake Browser/Vision and verify queued photo parameters, source identity, no
refetch, failures, Stop and receipt replay. Keep real hardware acceptance separate;
the prior image smoke matrix must not be rerun without a concrete reason.
