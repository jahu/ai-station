# Ask follow-up questions about an agent's actual result

A completed agent report visible in a conversation must also be usable by its
next Chat/Work reply. A queued-control sentence is not the report. Reuse the
source-bound control → ordinary agent Task/Run → verified report Artifact graph;
never search all agents for a plausible result or run the agent again to answer.

Resolve only a visible assistant control result from the same conversation.
Verify the succeeded controller and its exact linked Task/agent, the completed
ordinary report child and its unique nonpartial Markdown Artifact. Reuse the
existing bounded canonical/hash-checked artifact reader. Include a bounded quoted
excerpt plus source/control/workflow/report/artifact IDs, checksum and truncation
metadata in the new Run's frozen context. Missing, changed, unfinished, failed or
ambiguous sources produce an explicit unavailable/status reference, never invented
report contents or fallback to an older output. Keep the latest referenced execution per agent: a newer unfinished result must
not fall back to an older completed report. Deduplicate repeated references and retain only sources actually inside the context window.

Reference data grants no tool, model, source-file, host-path or network authority.
The current instruction and existing Chat/Work policy still decide actions.
Record provenance beside the actual reply with a compact source link and an
excerpt/unavailable label. Local and explicitly selected external providers keep
their normal disclosure/permission boundary; no credentials enter source context.
No new schema, execution service or native operation. No new workload is launched
just to read an existing result.

First qualify ordinary text reports; later extend the same verified-result
boundary to structured data/coding/media summaries and explicit artifact reuse.
Do not imply that absent code/media contents have been inspected. Preserve
independent scheduling and the unblocked main composer from #417.

Verify actual report bytes in Chat and Work context, history/provenance bounds,
source hash/owner/Task tampering, partial/deleted/failed/active results, repeat
reference deduplication, mode/permissions and malicious quoted instructions.
Qualify compiled desktop/mobile follow-up/reload separately from real inference.
The previous live baseline is qualified #417; use the shared deployment record
and this increment’s post-deployment qualification for the actual running image.
