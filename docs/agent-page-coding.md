# Build from reviewed public pages

A Local coding agent may also select HTTP fetch and save 1–3 public URLs. Review
the linked project, goal, URLs, model and optional approval before activation.
The factory can draft this combination from an explicit website-building goal
containing public URLs; drafts remain disabled and never invent a project.

Execution remains one Task: optional approval → reviewed HTTP reads → context
preparation → existing isolated worktree/proposal/validation. No coding worktree
or model inference starts before every page read succeeds. The HTTP tool retains
its URL/DNS/redirect/SSRF rules, bounded text artifacts, cancellation and history.
Fetched text is quoted untrusted reference material, never tool permissions or
project commands. Coding guidance receives a bounded excerpt and source Run
provenance; full observations remain inspectable. The same total deadline applies
to reading and coding. Stop or failed reading prevents later publication.

External coding providers retain their existing exclusive-tool and explicit
source-sharing contract. This increment adds no arbitrary browsing, login,
external-provider sharing, commit, push or deployment.
