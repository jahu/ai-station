# AI Station 0.1.1

Your own AI. Made simple. No platform censorship.

A focused update for agent creation, scheduling and image workflows. Compatible
uncensored models are welcome; the model, its license and your hardware determine
what it can do. Local generation has no AI Station cloud quota or per-token fee.

## What's new

- **Recurring requests create agents.** A request such as “Co 15 minut generuj mi zdjęcie…” creates a disabled agent draft. Explicit cadence wins over a model's manual/default schedule; a 15-minute cadence becomes `*/15 * * * *`.
- **Approve directly in the conversation.** Review the draft, choose **Accept and Enable**, or open **Review and Edit**. Activation shows the next scheduled Run without silently generating an extra result immediately. Existing permissions, readiness checks and email consent remain in effect.
- **Choose the image model before enabling.** New image-agent proposals default to Qwen unless you name another supported engine. Qwen/Juggernaut selection is available in the conversation and full editor. Switching to Qwen clears incompatible seed and negative-prompt settings; Juggernaut's negative prompt is visible in Advanced.
- **Remove unwanted agents and projects.** Single and selected-page deletion uses confirmation and version checks. Active work blocks deletion. Removing a project pauses/unlinks its live agents while retaining original folders, repositories, worktrees, Runs and Library artifacts.
- **Readable agent results.** Generated media stays above workflow steps and execution history instead of covering them while scrolling. The Images workspace retains its own preview behavior.

## Install or update

Installers are prepared for Ubuntu 24.04 x86-64 and Windows 11 x64:

- `AI-Station-0.1.1-linux-amd64.deb`
- `AI-Station-0.1.1-windows-x64-Setup.exe`
- `SHA256SUMS`

Release preparation is in progress; published assets will be attached to
[the release](https://github.com/jahu/ai-station/releases/tag/v0.1.1) after the
owner reviews and merges the release PR into master. Never substitute renamed
0.1.0 installers for new packages.

Back up application data and finish active jobs before updating. Schema 0043 adds
agent/project deletion markers while retaining existing definitions and historical
references. Deleted definitions cannot be scheduled, re-enabled or used for new
work. Downgrading a database containing deleted definitions is intentionally
refused; restore a reviewed backup instead.

Windows remains unsigned under the owner's existing early-release decision.
macOS is not supported. Physical Windows NVIDIA qualification and human assessment
of media quality remain separate from automated/package checks. The detailed
platform setup and qualification scope is documented in [0.1.0](0.1.0.md).

## Validation

The included changes passed focused backend, API/privacy/migration/recovery tests,
frontend component tests, lint, typecheck, production builds and Docker builds.
Workstation checks verified real local drafting and desktop/mobile agent controls,
including actual settings saves and image/workflow geometry. No private Library
media is included in this release. Installer build and upgrade evidence will be
recorded before publication; earlier platform qualification is not a claim of new
physical GPU tests.

A sporadic SQLite lock was observed during concurrent browser/API reads in local
QA. It is tracked separately; this patch does not claim a general database
concurrency fix.
