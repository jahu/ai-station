# AI Station 0.4.0 — A steadier voice

## What changes

- New speech and avatars default to **Even voice volume**: local CPU processing
  smooths changes between loud and quiet passages, limits peaks, and preserves
  the words, pace and pauses. Turn it off to keep original dynamics.
- Existing WAV speech and MP4 avatars have **Even out voice volume** in Library.
  This creates an ordinary inspectable Task/Run and a separate balanced copy.
  Originals stay intact. Progress, Stop and the result link remain beside the media.
- Avatar repair copies video packets without re-encoding the picture, checks
  video timestamps and preserves audio timing. Already balanced speech is not
  processed a second time when an avatar uses it.
- No additional AI model, GPU work or cloud service is involved. Music and sound
  effects are not automatically treated as speech. There is no database migration.
- Windows preserving updates now accept standard owned `~/.local` parent
  permissions. Private application directories remain protected; existing user
  directories are not chmodded. An early rejected transfer gets a clear
  saved-work-preserved explanation instead of a raw pipe error.

## Install or update

- `AI-Station-0.4.0-windows-x64-Setup.exe` — Windows 10 21H2/22H2 or 11 x64.
- `AI-Station-0.4.0-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.4.0-QA.zip` — operator workbook and neutral fixtures.
- `SHA256SUMS` — package checksums.

Finish active work, back up application data and keep your existing data directory
when updating. Windows 10 still requires KB5020030 or a newer cumulative update;
setup guides WSL preparation. Windows installers remain unsigned under the owner's
existing decision. macOS remains unsupported; physical Windows GPU inference is
not newly qualified by this CPU-processing release.
