# AI Station 0.8.1 — Personal memory and a smoother Chat

AI Station can now remember useful personal context across conversations. Open
**Memory → Learn from conversations** to enable it for your account. For example,
give Chat your preferred name, then ask for it in a new conversation. Correct the
name in a later chat, or review, edit, disable and forget the entry in **Memory**.

- **Personal memory:** learning uses a local model and starts off by default.
  Local semantic indexing supports recall when an encoder is configured. Both
  conversation replies and the assistant planner receive relevant saved context.
  Inspect why a memory was saved and which sources informed a reply.
- **Your controls:** switch off learning or recall across your account, or disable
  memory for a single conversation. Older chats are processed only when you
  explicitly choose **Learn from earlier chats**. An external Chat provider can
  receive recalled context in its request when you select that provider.
- **Chat toolbar:** Memory sits beside Web search, with visible On, Saved and Off
  states in new and ongoing conversations.
- **More reliable background refresh:** conversation history and memory settings
  read while the database is writing. A timed-out write now explains that the
  station is busy and can be retried.

The installer preserves existing station data and upgrades the database to
migration 0048. The supported downloads are the x64 Windows 10/11 installer and
the amd64 Ubuntu 24.04 package. Windows Setup is unsigned. macOS remains deferred.

See [Memory](../memory.md) for details and the
[implementation record](../plans/personal-conversation-memory.md) for local-model,
encoder and account-isolation verification. Existing [Live functionality](0.8.0.md)
is available with the same hardware requirements.
