# AI Station 0.6.2 — Reliable edits, clearer results

One Edit operation, clearer conversation results and stronger checks before an
edited image is accepted. This release also repairs image-series continuation
and keeps the composer usable after adding references.

## Highlights

- One public **Edit** operation for one or several references; existing history,
  saved definitions and legacy API modes remain compatible.
- New edits inspect original references, plan concrete changes and compare the
  actual output with the request. Unchanged pixels cannot count as an edit.
- Independent local technical-quality checks can reject material rendering damage
  even when a requested semantic change happened. Explicit artistic effects remain
  valid. One bounded correction preserves original references and the chosen model;
  unresolved uncertainty is reported as a failure, not a verified image.
- Fresh automatic image seeds avoid replaying reference noise. Explicit seeds
  and saved transport retries remain reproducible.
- Automatic model selection uses captured installed capabilities; explicit model
  choices remain authoritative. Native engine configuration is honored without
  modifying the external photo pipeline or host drivers.
- Closed image reasoning uses native JSON responses while preserving multimodal
  inputs and exact reference indices, including two batches for eight references.
- Separate image series keep their original references and ordering when a
  continuation planner omits them. Actual normalized bindings remain inspectable.
- Final artifacts appear directly below the answer, above collapsed Task activity.
  Active progress stays visible; the history can be reopened without duplicating
  result images/players. Agent-definition review remains visible outside the fold.
- Image attachments no longer make the chat composer or Send controls unreachable.
- Five new operator QA scenarios cover these workflows with neutral media.

## Install or update

- `AI-Station-0.6.2-windows-x64-Setup.exe` — Windows 10 21H2/22H2 or 11 x64.
- `AI-Station-0.6.2-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.6.2-QA.zip` — operator workbook and neutral fixtures.
- `SHA256SUMS` — exact package checksums.

Compatible installed clients use **Settings → Updates → Update and restart**
after publication. Retain the same application data location. Windows installers
remain unsigned; macOS remains unsupported. Existing model files, external runtimes
and NVIDIA drivers are not replaced by this release.

## Verification

The integrated image/controller/runner changes passed 898 affected backend/native
tests, repository lint/format and production Docker builds. The conversation UI
passed 1,254 tests plus lint, TypeScript and a production build. Actual Chromium
checks used neutral synthetic media at desktop/mobile sizes. The reported real
conversation projects three distinct final image artifacts in production order.

Real local vision checks reject the reported washed-out output, accept a clear
quality-positive control and accept intentional fading when explicitly requested.
An ordinary deployed worker independently rejected the damaged file. Earlier
qualification and its boundaries are recorded in [verified editing](../plans/unified-image-editing.md),
[action contracts](../plans/model-aware-orchestrator-actions.md) and
[seed diagnosis](../plans/qwen-reference-seeds.md). A successful local visual
check is not a guarantee of perfect model perception or identity preservation.

Release-specific packaging, offline API/fake-executor checks, native Windows
compiler evidence and checksums are recorded with the reviewed release PR. No
new physical Windows GPU acceptance or fresh complete three-image GPU series is
claimed. The QA catalog is v60 with 304 active cases; exported operator answers
start untested.

Publication follows the human owner's approval and merge into master. The
immutable `v0.6.2` tag will be created on that merged master commit.
