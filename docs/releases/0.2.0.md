# AI Station 0.2 — Find your next local model

Add compatible models after setup, without assembling a new inference stack.
**Models → Find new models** starts with what you want to create and checks the
fit before downloading weights. Search public Hugging Face sources or paste a
repository/file link. Keep your existing conversations, agents and creative work.

## What changes

- **Discovery for seven uses.** Conversation, images, video, voice, music, avatars
  and memory, with popular/recent public results and small hardware comparisons.
  Labelled runtime starting points pass the same inspection as publisher matches.
- **Hardware first.** Check each GPU, actual sharding, context/KV cache, physical
  RAM and free application storage. The complete model and companion files count,
  including multipart GGUFs. Busy resources, unknown requirements, access-gated
  sources and unsupported graphs remain distinct from an estimated fit.
- **One reviewed installation.** Pinned revisions, hashes and licenses feed the
  existing Task → Run → Events → Artifacts lifecycle, with progress, Stop, resume
  and native verification. Installation does not grant permission to use cloud
  providers or change unrelated runtimes.
- **Choices that stay yours.** Installed models appear in compatible workspaces
  and assistant/agent settings. Shared GGUF parts retain independent model choices;
  removal/restore preserves their identities without deleting cached weights.
  Publisher update review is explicit and never silently replaces a selection.
- **Less repeated transfer.** Plans distinguish total model size, reusable owned
  weights, estimated download and additional disk reserve. Reuse is advisory until
  the installer rehashes and the Runner verifies the actual complete objects.
- **Operator QA.** The Polish workbook contains 277 active cases, neutral fixtures
  and space for results, bugs and improvements. Every operator result starts
  untested; internal qualification is recorded separately.

## Supported discovery families

| Use | Current admitted family |
| --- | --- |
| Conversation and supported agent LLMs | Supported llama.cpp GGUF architectures, including compatible complete split GGUFs |
| Images | Qwen Image 2.1 checkpoint slot |
| Video | F16 Wan 2.2 TI2V 5B diffusion slot |
| Speech | Chatterbox multilingual v3 T3 slot |
| Music | ACE-Step 1.5 checkpoint slot |
| Avatars | Sonic adapted UNet slot |
| Memory | Compatible multilingual E5 CPU encoder bundles |

A source result is not an automatic adapter for every new architecture. Graph,
format, companions and runtime must agree. An estimated fit is not an inference
quality/speed benchmark. Explicit workload offload policies remain visible;
discovery never introduces an implicit CPU or cloud fallback.
[Detailed model contracts and actual tests](../models.md).

## Install or update

After owner review and promotion to master, assets are published under
[v0.2.0](https://github.com/jahu/ai-station/releases/tag/v0.2.0):

- `AI-Station-0.2.0-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.2.0-windows-x64-Setup.exe` — Windows 11 x64.
- `AI-Station-0.2.0-QA.zip` — Excel workbook, CSV files and neutral fixtures.
- `SHA256SUMS` — verify the downloaded files.

Finish active work and back up application data before updating. Alembic 0044
adds logical model binding keys and uniqueness constraints; legacy primary model
references remain valid. Downgrade refuses to discard additional bindings.
Existing accounts, conversations, artifacts and owned weights are retained.
Never roll an old application over a newer database without a compatible backup.

## Validation and release gates

Discovery was reviewed incrementally through PRs #645–668. Recorded Linux checks
include real public model download/native verification and conversation/agent
execution, and separate selected-model image, video, speech, memory, music and
Sonic avatar qualification. Split transfer interruption, native Runner restart,
Stop and resource release have separate evidence. Seven-capability live metadata
checks and desktop/phone browser checks cover the guided entry. See the precise
scope and caveats in [the model guide](../models.md), rather than treating every
installed model or setting as hardware-tested.

The release candidate still requires frozen Linux/Windows installer checks,
release-specific QA export and owner-reviewed master promotion. Packaging evidence
will be recorded with the reviewed candidate before publication. Production 0.1.2
has not been replaced merely by preparing these notes.

## Platform notes

Linux NVIDIA execution is qualified only for the recorded models and presets.
Windows installation and CPU checks are separate from physical Windows NVIDIA
inference, which the owner scheduled after release. Human evaluation of voice and
film samples also remains a manual follow-up. macOS remains unsupported.

The Windows installer is unsigned by owner decision. Windows may show an unknown
publisher or block the file under its security policy. OS protections are not
disabled by the installer. SMTP/push integration is outside this release scope.
No private Library media or new unapproved screenshots are published.
