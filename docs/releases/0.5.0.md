# AI Station 0.5.0 — Updates made simple

## What changes

- Your running version appears discreetly in the sidebar. Installed clients
  check the official stable release channel and show an available-update link.
- In **Settings → Updates**, administrators can review release notes/download
  size and choose **Update and restart**. The desktop owner downloads and verifies
  the exact official package, waits for idle work, preserves application data,
  updates and restarts. No separate installer wizard needs opening.
- Downloads show progress and allow cancellation before activation. Interrupted
  activation retains its original operation; native **Continue update** inspects
  that operation instead of launching an uncertain installer again.
- Windows has the AI Station icon in its installer, app, window and tray, and one
  primary setup action for the current stage. Background Stop/exit requests finish
  normally after any in-flight status check.
- A separate [illustrated installation guide](https://ai-station.dev/install/)
  covers Windows/Ubuntu, the first account/model and troubleshooting. Landing-page
  and README links keep it easy to find.

## Install or bootstrap

- `AI-Station-0.5.0-windows-x64-Setup.exe` — Windows 10 21H2/22H2 or 11 x64.
- `AI-Station-0.5.0-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.5.0-QA.zip` — operator workbook and neutral fixtures.
- `SHA256SUMS` — exact package checksums.

**Version 0.4 and older need this desktop client installed once.** Those clients
cannot gain a missing native update owner through a browser update. Finish active
work and use the existing preserving installation path, keeping the same data
location. Later compatible releases can use the in-app action. Source/development
checkouts retain their normal Git workflow and do not offer unsafe self-rewrites.

Windows installers remain unsigned. Windows 10 requires KB5020030 or a newer
cumulative update; setup guides WSL preparation. macOS is unsupported. This release
adds no model download, cloud requirement or driver changes. It does not newly
qualify physical Windows GPU inference or physical Windows 11 execution.
