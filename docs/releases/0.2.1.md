# AI Station 0.2.1 — Easier model management

Find and download your next local model without searching for small links.
Open **Models → Add model** for hardware-aware recommendations, model-name search
or a public Hugging Face repository/file link.

## What changes

- A prominent **Add model** action and large download/setup cards.
- Shared **Installed models**, **Browse & download** and **Quick setup** navigation,
  including on narrow phone screens and model details.
- Clear choose → review fit → install progress. Recommendations and source searches
  still inspect metadata before any explicit, reviewed download.
- Quick setup shows the selected category: Conversation, Images, Video, Voice,
  Music, Avatars, Memory or Sound effects. Existing direct links and browser history
  remain available; each category retains its saved preparation history.
- **Scan local folders** explicitly scans configured local roots. Saved models and
  local files have clearer labels; format/runtime details are expandable.
- An updated Polish operator workbook: catalog v54, 278 active cases, including
  model-management navigation. All operator answers start untested.

The model families, permissions, installation/recovery contracts and storage
boundaries are those of [0.2.0](0.2.0.md). See [the model guide](../models.md) for
supported families, hardware assessments and the precise inference qualifications.

## Install or update

After owner review and promotion to master, assets are published under
[v0.2.1](https://github.com/jahu/ai-station/releases/tag/v0.2.1):

- `AI-Station-0.2.1-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.2.1-windows-x64-Setup.exe` — Windows 11 x64.
- `AI-Station-0.2.1-QA.zip` — Excel workbook, CSV files and neutral fixtures.
- `SHA256SUMS` — verify downloads.

Finish active work and back up application data before updating. This patch adds
no database migration: schema remains 0044. Accounts, conversations, artifacts,
models and saved configurations are retained. Use the normal installer/update
path and preserve your data.

## Validation

The UX change passed all 1,149 frontend tests, lint, TypeScript, formatting and a
production build. Compiled Chrome checks at desktop and phone widths cover visible
primary actions, category navigation, history and keyboard variant review using
fixture API responses and saved public metadata. The reviewed application image
was deployed to the development station with its accounts/settings preserved;
checks verified the served bundle over loopback and LAN and the existing native
Runner connection. No new model inference was claimed for these UI changes.

Release-candidate packaging, version checks, preserving update and actual native
Windows installer build are verified separately before publication. The release
PR records their final results and source identity.

## Platform notes

The platform qualification remains that of 0.2.0. macOS is unsupported. Physical
Windows NVIDIA inference and human voice/film evaluation remain the owner's
post-release follow-up, separate from installation and CPU checks. The Windows
installer remains unsigned by owner decision; an unknown-publisher warning or
local policy may block it. No new private Library media is published.
