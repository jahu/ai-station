# AI Station 0.7.0 — Keep the motion going

## Highlights

- **Continuous video with SVI Pro Q4:** a fixed, owned Wan 2.2 profile carries the
  original image and recurrent motion context between windows. It improves longer
  scenes without asking each segment to reconstruct everything from one RGB frame.
- Landscape 832×480 and portrait 480×832 at 15 fps. Select the installed model in
  Video, Chat, agents or Studio; explicit model, format and length choices survive
  the conversation handoff. Existing Wan models and saved history remain available.
- Guided preparation verifies pinned model and engine inputs. Generation retains
  normal Task → Run → Events → Artifacts, resource admission, owned cancellation
  and recovery. Compatible completed windows can support Resume.
- Existing generated-sound and timeline tools support these 15-fps results.
- Operator QA catalog v61 adds four video cases; all 308 exported answers start
  untested. No private test media are bundled with the release.

## Requirements and actual results

The new profile was qualified on Linux x86-64 with one RTX 3060 12 GB and an
18-GiB zero-swap memory reservation, on a workstation with 32 GB RAM. Two cards
were present; these measurements do not claim dual-GPU acceleration.

Complete local results include a 20-second landscape human scene, two 10-second
portrait seeds and a 10-second vehicle scene. Each 10-second generation took about
1 h 46 min; 20 seconds took 3 h 32 min. Sampled whole-film views and window joins
retained the principal subject and setting. The owner reports visible improvement.

Detail remains approximately 480p. Framing and secondary actions are imperfect:
feet can leave a portrait frame, and one seed missed the requested final gaze.
These are measured improvements, not a guarantee for every future generation.
Actual generated sound passed timing/decode checks; subjective listening is not
claimed. See [benchmarks](../benchmarks.md) and the
[qualification record](../plans/long-video-temporal-quality.md).

## Install or update

After publication, compatible installed clients can use **Settings → Updates →
Update and restart**. Retain the same application data location. Existing models,
external runtimes and NVIDIA drivers are preserved. The SVI engine and weights
are optional downloads through **Video → Set up video → Continuous video**.

Linux and Windows installers remain supported; the new real GPU qualification
above is Linux only. Windows physical-GPU acceptance is separate. Windows
installers remain unsigned under the existing early-release decision. macOS
remains unsupported.

## Verification

The video implementation passed the complete ordinary Python suite (10,233 passed,
25 skipped), plus six Node-dependent Python cases rerun successfully with Node on
PATH. The frontend passed 1,276 tests, lint, type checks and a production build.
Both Compose configurations, the exact development image and its offline
API/separate fake-worker/SSE/restart smoke passed. Actual GPU model qualification
is separate from these fake-executor checks.

Release-version package builds, exact packaged-image checks and their checksums
will be recorded before the release PR is handed to the owner. Preparation does
not publish a release: only the human owner may approve and merge into master;
the immutable tag is created on that merged master commit afterward.
