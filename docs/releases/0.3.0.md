# AI Station 0.3.0 — Connected conversations and image agents

Describe a sequence of tasks in one conversation. The assistant chooses available
tools, observes actual results and passes those results to the next operation.

## What changes

- A durable LlamaIndex ReAct orchestrator over the existing Task → Run → Events →
  Artifacts engine, with inspectable tool actions, Stop and scoped permissions.
- Image references survive clarification and intervening messages. Earlier
  requests provide context without becoming an unwanted work queue again.
- Modify an image, then draft a recurring agent using that exact new result,
  compatible rendering profile and requested schedule. Drafts remain disabled
  for review; generated instructions do not activate schedules.
- Generic image-agent variation planning records concrete changes and recent
  results without assuming every reference depicts a person.
- Image transformations honor the configured per-operation editor. Krea reference
  operations explicitly choose anchored framing or a new composition before
  dispatch; older queued policies remain compatible.
- Existing agents expose installed compatible models for Generate, Edit and
  Recompose beside the image operation. Model changes retain briefs/references,
  apply suitable settings and reject unsupported reference counts.
- SQLite contention handling and process-journal locking repairs protect media
  execution and replacement-owner bookkeeping.
- Polish operator QA catalog v55 adds four cases; 282 cases begin untested.

## Install or update

Release assets will be published after owner approval and promotion to master:

- `AI-Station-0.3.0-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.3.0-windows-x64-Setup.exe` — Windows 11 x64.
- `AI-Station-0.3.0-QA.zip` — Excel workbook, CSV files and neutral fixtures.
- `SHA256SUMS` — download checksums.

Finish active work and back up application data before updating. This release
migrates schema 0044 → 0045, adding durable observed-tool dependencies. Use the
normal installer/update path and retain application data. Accounts, conversations,
artifacts, registered models and saved definitions must survive the upgrade.
Published older tags remain unchanged.

## Platform notes

macOS remains unsupported. Windows installers remain unsigned by owner decision;
Windows may show an unknown-publisher warning or local policy may block them.
Physical Windows NVIDIA inference and human evaluation of voice/film quality
remain separate from installer qualification. No new model weights or private
Library media are included in this release. New tool chains remain bounded by
available integrations, permissions, approvals and execution budgets.
