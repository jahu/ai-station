# AI Station 0.3.1 — Reliable conversations and working website results

## What changes

- Requests to build a website use an isolated owned project and return actual
  checked HTML/CSS/JS/assets, ZIP download and an interactive preview. Original
  user intent and fetched source facts survive planning and bounded repair.
- Chat retains received stream batches through transient SQLite BUSY/LOCKED
  writes, without replaying inference. Stale workers cannot overwrite recovery.
  Structured tool failures remain usable by the next controller decision.
- Local coding separates token-stream metadata from code limits, uses a dedicated
  output budget and constrained owned llama.cpp output formats. New static sites
  get fixed offline checks/builds; path permissions and review remain enforced.
- Resource waits back off rather than spinning; HTTP response delivery and model
  catalog reads avoid retaining SQLite writers. Member uploads stay visible
  after backups. Completed talking avatars satisfy requested video outcomes.
- English Chatterbox speech selection and refreshed public demonstrations show
  local voices, music, video, workspaces and general-purpose autonomous agents.
- Long recorded validation commands use a compact disclosure on desktop/phone,
  with the exact command still available for inspection.

## Install or update

Release assets:

- `AI-Station-0.3.1-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.3.1-windows-x64-Setup.exe` — Windows 11 x64, unsigned.
- `AI-Station-0.3.1-QA.zip` — operator workbook, CSV files and neutral fixtures.
- `SHA256SUMS` — download checksums.

Finish active work and back up application data before updating. Use the normal
installer/update path and retain application data. Schema remains 0045; this
patch introduces no new migration. Accounts, conversations, artifacts, models and
saved definitions must survive updates. Published tags remain immutable.

## Validation

The underlying repairs passed the reviewed backend/Runner regression suites,
frontend checks and production image build. A real authenticated request to
rebuild a public website completed page read → captured-reference read → owned
code on its first coding attempt. Its ten-file verified ZIP retained actual
source contact/news facts without missing or runtime-network assets. Native
previews and authenticated Chat checks ran at desktop and phone widths. A real
local Chat smoke matched persisted messages to streamed deltas. Original failed
conversations and partial output were preserved.

## Platform and review notes

Generated website code is a proposal for review, not automatic publication or a
production-design guarantee. Existing permissions, approvals, isolated worktrees
and bounded execution remain in force. No models or private Library files ship
in these packages. macOS remains unsupported. Windows installers remain unsigned
by the owner's decision; Windows may display an unknown-publisher warning or
local policy may block them. Physical Windows NVIDIA inference remains separate
from package/native installer qualification.
