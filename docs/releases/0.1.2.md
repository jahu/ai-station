# AI Station 0.1.2

Your own AI. Made simple. No platform censorship.

A focused update to the Library and media-job reliability, with refreshed website
information and direct Linux/Windows downloads.

## What's new

- **Find every reference.** Input pickers in agents, media workspaces, chat and the
  timeline search the stored private collection, not just the first page. Older
  files load as you scroll, with a Load more/retry button. Ordered image selection
  survives paging and searches. Each operation still shows compatible formats.
- **Bigger image previews.** Reference cards show the whole image with larger
  previews on desktop and mobile.
- **A media-first Library.** Images, video and audio are visible by default. Files
  and All retain JSON reports and documents; Run history is unchanged.
- **Film and avatar previews.** Cards show a still from the actual existing film.
  Preview decoding is lazy, silent and does not autoplay or start GPU generation.
- **Keep the original media job.** Temporary SQLite write contention no longer
  makes a media worker abandon polling. An expired, matching owned media journal
  can resume inspection and result collection without dispatching inference again.
  Worker claims, permissions, allocations, deadlines and Stop remain authoritative.
  Unknown identity, unavailable exit status or uncertain cleanup still requires
  inspection. This is not an automatic retry of arbitrary external actions.
- **Updated website and QA.** Download/version links share one configuration,
  release highlights cover current behavior, and the Polish QA workbook adds
  Library/search/preview and concurrent-generation cases.

## Validation

The Library change passed 31 focused backend/private-account/purge tests, all
1,091 frontend tests, frontend checks/build, Docker build and actual browser checks
against the shipped frontend: 122 images behind 130 JSON reports, scrolling through
every page, oldest-image search, large cards, film/avatar decoded frame checks
and desktop/mobile layout.

Media supervision passed 189 lifecycle/media/private-account cases and 123 adapter
cases, global Python/Runner lint/format, image builds and isolated Docker
API/worker/native-UDS smoke tests. Real SQLite contention and actual owned fixture
subprocesses verified single dispatch, inspection handoff, Stop, logs and result
collection. These fixture tests run without model inference. Both fixes were
reviewed, merged into develop and deployed on the reference workstation.

Installer build/update evidence and website checks are recorded in the release PR
before publication. Previous physical hardware results remain historical results,
not new GPU smoke tests for this patch. No private Library media is published.

## Platform notes

Windows remains unsigned under the existing early-release decision. SmartScreen
may identify an unknown publisher; Smart App Control or managed policies may block
the file. Do not disable OS protections. See [platform setup/qualification](0.1.0.md).
Physical Windows NVIDIA qualification and human evaluation of voice/film quality
remain post-release checks. macOS remains unsupported.

The SQLite correction covers a confirmed media-supervision failure and the
scheduler's transaction across telemetry I/O; it is not a claim that every possible
database contention source or unrelated integration failure has been eliminated.
