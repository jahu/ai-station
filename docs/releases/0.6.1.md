# AI Station 0.6.1 — Images that flow through chat

Paste a screenshot into the conversation, find a real photograph online and pass
that saved reference to image editing. Rich image instructions no longer fail
because the intent summary exceeds 500 characters. The public website now gives
Creative Studio its own explanation for reels, presentations and educational films.

## Highlights

- Ctrl+V images/screenshots and supported text/PDF documents into new or existing
  conversations, using the normal attachment validation, previews and removal.
  Additional images retain earlier references within the four-image limit.
- Typed image search and import with Web enabled. Original references are saved
  privately in Library and shown in chat alongside the later edited output.
- Bounded public downloads with pinned DNS, checked redirects, actual pixel
  decoding, provenance, cancellation and lease/claim checks.
- Shared 4,000-character intent descriptions; original instructions stay intact.
- A responsive Creative Studio section on the public site; no new private media.
- Four new operator QA scenarios. Operator answers start untested.

## Install or update

- `AI-Station-0.6.1-windows-x64-Setup.exe` — Windows 10 21H2/22H2 or 11 x64.
- `AI-Station-0.6.1-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.6.1-QA.zip` — operator workbook and neutral fixtures.
- `SHA256SUMS` — exact package checksums.

Compatible installed clients use **Settings → Updates → Update and restart**
after publication. Preserve the same application data location when using the
installer. Windows installers remain unsigned; macOS remains unsupported.
