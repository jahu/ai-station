# AI Station 0.6.0 — Creative Studio

Create branded reels, presentations and educational films from one conversation.
Studio brings reusable brand identities, real visual sources, narration, music,
a speaking presenter and complete export/version history into the same workflow.

## Highlights

- Brand projects with their own palette, typography, tone, audience and defaults.
  Projects are optional; standalone materials work too.
- Reels, presentations and films in portrait, landscape or square format, with
  editable storyboards, generated images/video, Library sources and motion.
- Narration, instrumental music or both, measured speech timing, editable phrase
  expression hints, and consistent speaker identity across speech chunks.
- Speaking presenters created from an authorized portrait and the film's actual
  narration, then composed alongside the story.
- Follow-up edits in chat: change a headline while retaining the actual media,
  exact soundtrack and previous versions. A different brand creates a separate
  copy instead of moving or overwriting the original.
- Whole-production progress, Stop, bounded recovery and inspectable source/Run
  history. Earlier queued work retains its captured contracts.
- GPU admission and expired-queue fixes accumulated since 0.5.0.
- Updated operator QA workbook with eight Creative Studio scenarios. User results
  start untested; internal verification is reported separately.

## Install or update

- `AI-Station-0.6.0-windows-x64-Setup.exe` — Windows 10 21H2/22H2 or 11 x64.
- `AI-Station-0.6.0-linux-amd64.deb` — Ubuntu 24.04 x86-64.
- `AI-Station-0.6.0-QA.zip` — operator workbook and neutral fixtures.
- `SHA256SUMS` — exact package checksums.

Compatible installed 0.5 clients can use **Settings → Updates → Update and
restart** after publication. Earlier clients need the preserving desktop installer.
Keep the same application data location. Source checkouts retain their Git workflow.

Studio's fixed local renderer preparation and required AI models are guided from
the application; this release does not bundle model weights or modify drivers.
Windows installers remain unsigned. Windows 10 requires KB5020030 or newer.
macOS remains unsupported. The CPU-only Windows VM does not qualify physical
Windows GPU inference or a physical Windows 11 machine.

## Verification

See the [Studio completion audit](../plans/studio-completion-audit.md). Real local
checks include a 75-second Full HD educational film, with all 179 original spoken
words and owner-approved narration throughout; portrait/music and landscape/silent
films; a standalone voiced reel; and a complete film with a generated Sonic presenter.
Actual follow-ups produced a 16-second headline edit and a separately branded
widescreen copy, preserving every source/trim, score and original history. Full
decoding, frame/source/audio checks and sampled visual review passed.

The Studio implementation passed 482 relevant regression tests and its final
alias correction passed 38 intent/binding/contract tests. Frontend lint,
TypeScript, action-result tests, production build, Compose and packaged API/
migration/account checks passed. Hosted Actions remain manual. Package-specific
verification and exact asset hashes will be recorded after the clean release build.

Private media are not included in public release assets or the website. A model's
individual output still needs editorial review before publication.
