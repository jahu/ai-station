A FEW GOOD QUESTIONS

Before you
plug in.

Still curious?
Join the conversation ↗

Does everything run locally?+

Configured local LLM and media workflows run on your workstation. You can choose external providers, and tools such as web search need network access. The website itself has no analytics, account signup or external font requests.

Can I use my own models?+

Yes. Open Models → Find new models to search public Hugging Face sources or paste a model link. {{NAME}} checks supported model families, hardware and required files before a reviewed download. Compatible runtimes and OpenAI-compatible endpoints remain available. Finding a model does not make every architecture supported; the result explains what fits and what needs a runtime. Read the model guide.

Do I need two GPUs?+

No. The architecture discovers devices dynamically; the reference machine has two RTX 3060 cards, but that is not a requirement. Each workload must fit its runtime and hardware. Current exercised media paths use NVIDIA/CUDA; broader GPU compatibility is a roadmap goal.

Is it ready for a nontechnical user?+

That's who we're building it for. The goal is simple: download the app, follow the setup and start creating, without learning model servers or technical configuration. v{{VERSION}} packages Python and the app, guides required OS permissions and recommends models for your hardware. Model downloads still need storage and suitable RAM/VRAM. Windows CPU first use is tested; physical NVIDIA and human voice/film evaluation follow release. macOS is unsupported. Your feedback will help us make setup better. See qualification and known issues.

Is {{NAME}} open source?+

It is source-available under PolyForm Noncommercial 1.0.0. Permitted noncommercial use is free. Other commercial use requires a separate written license. Models and third-party components retain their own terms. Commercial licensing details.

Can I contribute?+

Yes — and testing is one of the most useful ways to help. Report a bug, tell us what felt confusing, improve the docs or suggest a feature. For code changes, contributors retain copyright and provide a signed agreement permitting commercial relicensing before merge. Start with the contribution guide.
